Founder · AI Builder · Researcher

Live site: https://yingda-yu.github.io/Dean-Yu-050325.github.io/

## Tech Stack

- HTML + CSS + vanilla JavaScript (no framework, no build step)
- Jekyll (GitHub Pages default)
- Canvas 2D for particle effects and visitor globe

## Updating Content

All text content (profile, projects, publications, timeline, etc.) lives in `assets/js/data.js`. Edit that file to update the website — no HTML changes needed.

### Publications

Publication data is in `SITE_DATA.publications.selected` (shown by default) and `SITE_DATA.publications.additional` (shown when "View all research" is clicked).

Papers with unverified metadata are kept as comments in the data file. Uncomment and fill in details once confirmed.

### To Add Links

Update these fields in `data.js`:

- `profile.linkedin` — LinkedIn URL
- `profile.googleScholar` — Google Scholar profile URL
- `profile.resume` — Resume/CV link
- `company.url` — Spartina Technology website
- Project `url` fields — individual project links
